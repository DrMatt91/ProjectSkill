# Как запустить проект с датасетом 12 ГБ

## Короткий ответ

**Не загружайте датасет в GitHub.** Репозиторий должен хранить только код, ноутбук и инструкции. Данные на 12 ГБ нужно запускать в облачной среде с GPU.

Рекомендуемый вариант для этой работы: **Kaggle Notebook + private Kaggle Dataset**.

Почему именно Kaggle:

- не нужно хранить 12 ГБ в репозитории;
- можно загрузить датасет один раз и подключать его к ноутбуку кнопкой **Add data**;
- есть бесплатный GPU в браузере;
- путь к данным стабильный: `/kaggle/input/<dataset-name>/...`;
- результаты ноутбука можно сохранить и приложить как `.ipynb` для сдачи.


## Формат вашего датасета: meta.json + ann/img

По присланному скриншоту у вас не папки классов и не `metadata.csv`. У вас JSON-разметка в формате, похожем на Supervisely:

```text
dataset/
├── meta.json
├── train/
│   ├── ann/
│   │   ├── ISIC_0012266.jpg.json
│   │   └── ...
│   └── img/
│       ├── ISIC_0012266.jpg
│       └── ...
├── valid/
│   ├── ann/
│   └── img/
└── test/
    ├── ann/
    └── img/
```

Для такого формата **не нужно** создавать `metadata.csv` и **не нужно** раскладывать изображения по папкам классов. Ноутбук сам:

- найдёт `meta.json`;
- возьмёт target-классы из тегов с `value_type = "none"`;
- проигнорирует служебные теги `age_approximate` и `sex` как target;
- сопоставит `ann/ISIC_0012266.jpg.json` с `img/ISIC_0012266.jpg`;
- использует готовое разбиение `train`, `valid`, `test`;
- создаст датафрейм с колонками `image_path`, `annotation_path`, `image_id`, `label`, `split`.

Если Kaggle после **Add data** положил датасет, например, в `/kaggle/input/projectskill-skin-lesions`, то обычно ничего менять не надо. Если автоопределение выбрало не ту папку, в ячейке загрузки данных задайте:

```python
DATA_DIR = Path("/kaggle/input/projectskill-skin-lesions")
```

Оставьте так:

```python
METADATA_PATH = None
TARGET_TAG_NAMES = None
```

Если нужно явно ограничить классы, можно задать:

```python
TARGET_TAG_NAMES = [
    "melanoma",
    "melanoma_or_nevus",
    "nevus_or_seborrheic_keratosis",
    "seborrheic_keratosis",
]
```

## Вариант A — Kaggle, рекомендуется

### 1. Скачать датасет

Скачайте архив по ссылке Cloud Mail на свой компьютер. Если архив уже есть локально, этот шаг пропустите.

### 2. Создать приватный Kaggle Dataset

1. Откройте Kaggle.
2. Перейдите в **Datasets → New Dataset**.
3. Назовите датасет, например: `projectskill-skin-lesions`.
4. Загрузите архив или распакованную папку целиком, не меняя структуру `meta.json`, `train/ann`, `train/img`, `valid/ann`, `valid/img`, `test/ann`, `test/img`.
5. Оставьте датасет приватным, если не хотите публиковать данные.

### 3. Создать Kaggle Notebook

1. Откройте **Code → New Notebook**.
2. В настройках справа включите GPU: **Accelerator → GPU**.
3. Если ваш тариф не позволяет включить **Internet**, оставьте интернет выключенным: ноутбук поддерживает offline-загрузку ImageNet-весов из локальных `.pth`-файлов.
4. Создайте отдельный private Kaggle Dataset с весами `torchvision` и загрузите туда файлы `resnet18-f37072fd.pth` и `mobilenet_v3_large-8738ca79.pth`.
5. Нажмите **Add data** и подключите два датасета: датасет с изображениями и датасет с весами.
6. Загрузите файл `notebooks/skin_lesion_classification_final.ipynb` или скопируйте его содержимое.
7. Запустите ноутбук сверху вниз.


### 3.1. Как подготовить веса без Internet в Kaggle

Для максимального балла по моделированию важно использовать pretrained-веса хотя бы для одной модели. Если Kaggle Internet недоступен, скачайте веса заранее на компьютере или в любой среде с интернетом:

```text
https://download.pytorch.org/models/resnet18-f37072fd.pth
https://download.pytorch.org/models/mobilenet_v3_large-8738ca79.pth
```

Затем загрузите эти два файла в отдельный private Kaggle Dataset, например `torchvision-imagenet-weights`, и подключите его к ноутбуку через **Add data**.

В ноутбуке по умолчанию стоит:

```python
PRETRAINED_WEIGHTS_MODE = "local"
```

Это значит, что `torchvision` **не будет скачивать веса из интернета**. Код будет искать файлы в `LOCAL_WEIGHTS_DIR`, `weights/`, `../weights/` и `/kaggle/input`. Если файлы не найдены, ноутбук остановится с понятной ошибкой, чтобы вы случайно не обучили модель без pretrained-весов и не потеряли баллы.

Если вы запускаете ноутбук там, где интернет разрешён, можно заменить режим на:

```python
PRETRAINED_WEIGHTS_MODE = "download"
```

Если pretrained-веса совсем недоступны, можно поставить:

```python
PRETRAINED_WEIGHTS_MODE = "none"
```

Но этот вариант хуже для оценки, потому что критерий моделирования отдельно поощряет использование предобученных весов.

### 4. Проверить путь к данным

В Kaggle данные обычно появляются в папке:

```text
/kaggle/input/<dataset-name>/
```

Ноутбук автоматически ищет структуру `meta.json` + `ann/img` в `/kaggle/input`. Если автоматический поиск выбрал не ту папку, задайте переменную окружения или вручную поменяйте `DATA_DIR` в первой ячейке загрузки данных.

Пример:

```python
DATA_DIR = Path("/kaggle/input/projectskill-skin-lesions")
```

### 5. Первый быстрый прогон

Для первого запуска не обязательно учить на всех 12 ГБ. Чтобы быстро проверить, что pipeline работает, задайте лимит изображений на класс:

```python
SAMPLE_PER_CLASS = 200
```

или в настройках окружения:

```bash
SAMPLE_PER_CLASS=200
```

После успешного прогона можно увеличить до `500`, `1000` или вернуть:

```python
SAMPLE_PER_CLASS = 0
```

`0` означает использовать все найденные изображения.

### 6. Что сохранить для сдачи

После запуска ноутбука обязательно сохраните `.ipynb` с outputs. В нём должны остаться:

- графики EDA;
- примеры изображений и аугментаций;
- графики loss и macro F1;
- таблица экспериментов;
- classification report;
- confusion matrix;
- threshold analysis;
- визуальная проверка correct / incorrect / uncertain;
- заполненные итоговые выводы.

## Вариант B — Google Colab

Colab можно использовать, если у вас достаточно места в Google Drive. Для архива 12 ГБ и распаковки может понадобиться заметно больше свободного места, поэтому Kaggle обычно удобнее.

Схема:

1. Загрузить архив в Google Drive.
2. Открыть ноутбук в Colab.
3. Подключить Drive:

```python
from google.colab import drive

drive.mount("/content/drive")
```

4. Распаковать датасет в `/content/data` или использовать папку на Drive.
5. Указать:

```python
DATA_DIR = Path("/content/data")
```

Минусы Colab для этого проекта: Drive может быть медленным для чтения тысяч изображений, а бесплатные сессии могут отключаться.

## Вариант C — локальный компьютер

Подходит только если есть:

- достаточно места на диске;
- Python/Jupyter;
- желательно NVIDIA GPU с CUDA.

Минимальная установка:

```bash
pip install -r requirements.txt
jupyter notebook
```

Данные положить в папку `data/`, затем открыть ноутбук и запустить сверху вниз.

## Что точно не делать

- Не коммитить датасет в GitHub.
- Не добавлять `.zip`, изображения, `*.pt`, `*.pth`, checkpoints в репозиторий.
- Не запускать финальное обучение только на CPU, если есть возможность использовать Kaggle GPU.
- Не сдавать ноутбук без outputs и без заполненных Markdown-выводов.
