# Итоговая аттестация: Data Science в медицине

Репозиторий содержит основу итогового Jupyter-ноутбука для задачи классификации изображений кожных поражений.

## Что внутри

- `notebooks/skin_lesion_classification_final.ipynb` — оформленный end-to-end шаблон ноутбука под финальную работу.
- Ноутбук включает разделы для EDA, проверки изображений, нормализации, аугментаций, stratified split, обучения ResNet18 и MobileNetV3, сравнения экспериментов, test-оценки, confidence threshold analysis и визуальной проверки предсказаний.

## Как использовать

1. Поместите датасет в папку `data/` рядом с репозиторием или измените переменную `DATA_DIR` в ноутбуке.
2. Если метки заданы папками, структура должна быть похожа на `data/class_name/image.jpg`.
3. Если метки находятся в таблице, задайте `METADATA_PATH`, `IMAGE_ID_COLUMN`, `LABEL_COLUMN` и `IMAGE_ROOT`.
4. Запустите ноутбук сверху вниз.
5. После выполнения ячеек заполните Markdown-выводы фактическими числами и наблюдениями.
6. Перед сдачей перезапустите ноутбук целиком и проверьте, что все графики и результаты сохранены.

## Важное медицинское ограничение

Полученная модель не должна использоваться как самостоятельный инструмент постановки диагноза. Корректный сценарий — система поддержки принятия решений врача с обязательной экспертной проверкой неуверенных и клинически рискованных случаев.
